# 理论闯关 · 遗忘曲线刷题

一个纯静态的刷题网页，用 **艾宾浩斯遗忘曲线** 调度 1012 道「理论闯关」题库（单选 + 多选），目标是把题目真正记住。

> 思路对齐「不背单词」：答对的题往后推、越熟隔越久；答错的题明天再见。一切以记住题目为主，而不是一次性刷完。

## 功能

- **遗忘曲线调度（SM-2 精简版）**
  - 答对「会了」→ 间隔 1 → 3 → 按难度系数拉长，间隔 ≥ 30 天记为「已掌握」
  - 答对「蒙的」→ 明天再见（不计入错误，不惩罚难度系数）
  - 答错「继续」→ 间隔归 1 天，难度系数下降
- **单选 + 多选**：单选点即作答；多选勾选后提交
- **多选巧记**：作答后展示记忆钩子（数字锚 / 点破干扰项 / 固定搭配），788 道多选全覆盖
- **键盘操作**：单选 `1–4` 直接作答；多选 `1–4` 勾选、回车提交；答对后回车=会了、空格=蒙的
- **本地进度**：全部存在浏览器 localStorage，导出/导入 JSON 可迁移设备
- **纯静态**：无后端、无构建步骤，数据打包进 `data.js`

## 使用

直接用浏览器打开 [`index.html`](index.html)，或访问 GitHub Pages 地址。

1. 首页设定「每日新题数」，点 **开始今日任务**
2. 作答 → 判「会了 / 蒙的 / 继续」
3. 任务完成后自动回到首页，待复习、新题、已掌握一目了然

## 题库

- 题量：**1012** 题（单选 313 + 多选 699）
- 来源：理论闯关在线题库（已去重、剔除脏题）
- 数据格式：`data.js` 内 `window.QUIZ_DATA = { counts, questions }`，题目结构：
  ```js
  { id, type: "single" | "multi", stem, options: [], answer: [选项下标], mnemonic }
  ```

## 技术

- 纯 HTML / CSS / 原生 JS，单页三视图（首页 / 答题 / 完成）
- 数据以 `<script src="data.js">` 注入 `window.QUIZ_DATA`（避免 `file://` 下 fetch 的 CORS 限制）
- 进度键：`lilun-quiz-state-v1` / `lilun-quiz-settings-v1` / `lilun-quiz-streak-v1`

## 部署

纯静态文件，任意静态托管皆可。GitHub Pages：

```
Settings → Pages → Source: Deploy from a branch → main / (root)
```
